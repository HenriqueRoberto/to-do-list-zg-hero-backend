# To-Do List ZG Hero - Backend

Aplicação para gerenciamento de tarefas em modelo Kanban (Backlog, To-do, Doing, Done). Toda a lógica de negócio (regras de validação, rebalanceamento de prioridade, organização das tarefas) fica no back-end, exposta para o front-end através de uma API REST.

## Tecnologias

- Java 21
- Spring Boot
- Gradle
- JUnit 5 + Mockito

## Como rodar

\`\`\`bash
./gradlew bootRun
\`\`\`

A API sobe em `http://localhost:8080`.
